# Composer une vitrine locale qui convertit

Un visiteur d'artisan veut savoir en 10 secondes : est-ce le bon métier, près de chez moi, sérieux, comment le joindre.

## Ordre de référence (1 page)
1. **En-tête collant** : logo/nom, téléphone cliquable (toujours visible sur mobile), bouton « Devis ».
2. **Hero** : métier + commune dans le titre (« Électricien à Villeurbanne et alentours »), une phrase de promesse,
   2 boutons (Appeler = primaire, Demander un devis = secondaire), un signal de confiance (note Google, années SI sourcées).
3. **Services** : 3 à 6 prestations concrètes, chacune avec une phrase utile (pas « Nous réalisons vos travaux d'électricité »).
4. **Pourquoi nous** : 3 arguments vérifiables tirés des sources (zone, réactivité annoncée, spécialité, avis). Si rien de sourcé, supprimer la section plutôt qu'inventer.
5. **Réalisations** : galerie 3–6 images (banque d'images en démo, photos du client après signature).
6. **Avis** : note globale + nombre + lien vers la fiche Google. Pas de texte d'avis recopié.
7. **Zone d'intervention** : commune du siège + voisines, carte statique légère ou liste.
8. **Devis** : formulaire court (nom, téléphone, commune, besoin, message), RGPD en une ligne.
9. **Pied de page** : coordonnées complètes, horaires, SIREN, mentions légales, politique de confidentialité.

## Choisir les variantes
- Alterner les fonds (clair, très clair teinté, sombre) pour rythmer : jamais deux sections consécutives identiques.
- Hero photo plein écran si une très bonne image de métier existe ; sinon hero typographique sur fond teinté avec
  élément graphique signature. Un hero photo médiocre est pire qu'un hero typographique.
- Services : grille de cartes si ≥ 4 ; liste détaillée avec icônes si ≤ 3.
- Ne pas utiliser toutes les sections disponibles : moins mais mieux. Une section creuse se supprime.

## Conversion
- Bouton d'appel atteignable au pouce sur mobile (barre d'action fixe en bas sur mobile : Appeler / Devis).
- Chaque section se termine sans impasse : un lien ou bouton mène vers l'action suivante.
- Formulaire : 5 champs maximum, étiquettes visibles (pas seulement des placeholders), message de succès clair.
- Pas de pop-up, pas de chat automatique, pas de cookie banner (aucun traceur sur nos sites → pas de bandeau nécessaire).

## Multi-pages (formule Pro)
Accueil + une page par service + pages locales « Métier à Commune » (contenu réellement différent par commune :
quartiers, types de logements, temps d'intervention annoncé si sourcé). Menu ≤ 6 entrées.
